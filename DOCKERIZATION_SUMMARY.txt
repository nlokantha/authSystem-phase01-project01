🎯 ARCHITECTURE OVERVIEW
================================================================================

Your system consists of 3 services running in Docker containers:

1. Node.js Application (Express)
   - Container: authsystem-app
   - Port: 3000
   - Purpose: REST API server
   - Image: node:22-alpine (lightweight)

2. PostgreSQL Database
   - Container: authsystem-postgres
   - Port: 5432
   - Purpose: Data storage
   - Username: authuser
   - Database: authsystem
   - Image: postgres:16-alpine

3. Redis Cache
   - Container: authsystem-redis
   - Port: 6379
   - Purpose: Session/Cache storage
   - Image: redis:7-alpine

All services are connected via Docker network for automatic service discovery.

🔧 AVAILABLE COMMANDS
================================================================================

DEVELOPMENT (macOS/Linux):
  ./docker.sh start      - Start all containers
  ./docker.sh stop       - Stop all containers
  ./docker.sh down       - Remove all containers
  ./docker.sh logs [svc] - View logs (app, postgres, redis)
  ./docker.sh migrate    - Run database migrations
  ./docker.sh build      - Build Docker image
  ./docker.sh rebuild    - Full rebuild & restart
  ./docker.sh shell      - Enter app container
  ./docker.sh postgres   - Connect to PostgreSQL
  ./docker.sh redis      - Connect to Redis
  ./docker.sh ps         - List running containers
  ./docker.sh clean      - Remove everything (careful!)
  ./docker.sh health     - Check container health

DEVELOPMENT (Windows):
  docker.bat start       - (same commands as above)
  docker.bat stop
  docker.bat logs
  docker.bat migrate
  (etc...)

DOCKER-COMPOSE (All platforms):
  docker-compose up              - Start services (foreground)
  docker-compose up -d           - Start services (background)
  docker-compose down            - Stop & remove containers
  docker-compose logs -f         - View all logs
  docker-compose ps              - List containers
  docker-compose build           - Build image
  docker-compose exec app <cmd>  - Execute command in app

PRODUCTION:
  docker-compose -f docker-compose.prod.yml up -d
  docker-compose -f docker-compose.prod.yml down
  docker-compose -f docker-compose.prod.yml logs -f

🚨 COMMON ISSUES & SOLUTIONS
================================================================================

ISSUE: "docker: command not found"
→ Docker not installed. Install Docker Desktop from docker.com

ISSUE: "Port 3000 already in use"
→ Kill the process using it:
  macOS/Linux: lsof -i :3000 | grep LISTEN | awk '{print $2}' | xargs kill -9
  Windows: netstat -ano | findstr :3000 (then taskkill /PID <id>)
  OR change port in docker-compose.yml

ISSUE: "Cannot connect to PostgreSQL"
→ Wait a few seconds for database to start
→ Check: docker-compose logs postgres
→ Verify DATABASE_URL in .env

ISSUE: "Cannot connect to Redis"
→ Wait a few seconds for Redis to start
→ Check: docker-compose logs redis
→ Test: docker-compose exec app redis-cli -h redis ping

ISSUE: "Services stopped unexpectedly"
→ Check logs: docker-compose logs
→ Check disk space: docker system df
→ Rebuild: docker-compose build && docker-compose up -d

For more troubleshooting, see DOCKER_SETUP.md

💡 PRO TIPS

Development:

  • Use ./docker.sh shell to run commands inside container

  • Volume mounts improve development speed
  • Health checks ensure reliability

  • Use secrets management for sensitive data
  • Regular base image updates
